# 🔐 Personal Password Manager

A beginner-friendly password manager built using Python. It allows users to save, view, and generate passwords for different websites through a simple command-line interface.

## ✨ Features

- Save website names and passwords.
- View all saved passwords.
- Generate random passwords.
- Store passwords in a text file.
- Automatically load previously saved passwords.
- Simple menu-driven interface.

## 🛠️ Technologies Used

- Python 3
- Random Module
- String Module
- Dictionaries
- File Handling
- Exception Handling

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Personal-Password-Manager.git
```

2. Open the project folder:

```bash
cd Personal-Password-Manager
```

3. Run the program:

```bash
python password_manager.py
```
